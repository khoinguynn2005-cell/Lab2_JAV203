Bài 5: Luồng điều hướng

  • View thông thường: trả tên template; model được render trong response hiện tại.
  • forward: server chuyển tiếp cùng request; URL trình duyệt giữ nguyên và request attributes/model có thể dùng tiếp.
  • redirect: trình duyệt tạo request mới đến URL đích; phù hợp Post/Redirect/Get, model thông thường không đi theo.
  • @ResponseBody: trả chuỗi/dữ liệu trực tiếp trong response, không tìm template.
